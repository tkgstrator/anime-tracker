# トップページ「最近更新されたアニメ」表示

## 概要

Hulu / Netflix のようなホーム画面をトップページに導入する。横スクロールのカルーセル行で「最近エピソードが追加されたアニメ」「今期の注目作品」などのセクションを表示し、ユーザーが一目で最新状況を把握できるようにする。

## 現状

- トップページ（`/`）はフラットなグリッド一覧 + フィルタ/検索のみ
- 「最近追加されたエピソード」「更新されたアニメ」を優先表示する仕組みがない

## UI デザイン（Hulu / Netflix 風）

### レイアウト構成

```
┌──────────────────────────────────────────────────┐
│  ヒーローバナー（今期の注目作品、任意）              │
├──────────────────────────────────────────────────┤
│  最近更新されたアニメ                        すべて→ │
│  [Card] [Card] [Card] [Card] [Card] →→→          │
├──────────────────────────────────────────────────┤
│  今期のアニメ                              すべて→ │
│  [Card] [Card] [Card] [Card] [Card] →→→          │
├──────────────────────────────────────────────────┤
│  録画予約済み                              すべて→ │
│  [Card] [Card] [Card] [Card] [Card] →→→          │
├──────────────────────────────────────────────────┤
│  プロバイダ別                                      │
│  Prime Video                              すべて→ │
│  [Card] [Card] [Card] [Card] →→→                  │
│  Hulu                                    すべて→ │
│  [Card] [Card] [Card] [Card] →→→                  │
└──────────────────────────────────────────────────┘
```

### 各セクションの定義

| セクション | データソース | ソート |
|-----------|-------------|--------|
| 最近更新されたアニメ | 直近7日間に `releaseDate` を持つエピソードがあるアニメ | エピソードの `releaseDate` 降順 |
| 今期のアニメ | 現在の `year` + `quarter` に該当するアニメ | `updatedAt` 降順 |
| 録画予約済み | `scheduled: true` のアニメ | `updatedAt` 降順 |
| プロバイダ別 | プロバイダごとにグループ化 | `title` 昇順 |

### カルーセル行の仕様

- 横スクロール（CSS `overflow-x: auto` + `scroll-snap-type`）
- 左右スクロールボタン（デスクトップのみ、hover で表示）
- カード幅: モバイル 160px / デスクトップ 200px 程度
- 1行あたり最大 20 件取得、先頭 10 件を表示
- 「すべて→」リンクで既存の一覧ページにフィルタ付きで遷移

## 実装タスク

### 1. バックエンド: セクション別 API 追加（1日）

既存の `GET /api/anime` にクエリパラメータを追加する方式と、専用エンドポイントを追加する方式がある。
既存 API の拡張が自然。

#### 1-1. 「最近更新」クエリ対応

`GET /api/anime` に `recentlyUpdated=true` パラメータを追加する。

```typescript
// 直近7日間にリリースされたエピソードを持つアニメを取得
if (recentlyUpdated) {
  const sevenDaysAgo = dayjs().subtract(7, "day").format("YYYY-MM-DD");
  // エピソードの releaseDate >= sevenDaysAgo を持つアニメを
  // 最新エピソードの releaseDate 降順でソート
}
```

#### 1-2. 「今期」クエリ対応

既存の `year` + `quarter` フィルタで対応可能（追加実装不要）。

#### 1-3. レスポンス最適化

ホーム画面用に複数セクションを1リクエストで返す専用エンドポイントも検討可能。

```typescript
// GET /api/home
// → { recentlyUpdated: Anime[], currentSeason: Anime[], scheduled: Anime[] }
```

ただし、既存 API を使い回す方がシンプル。フロントから複数リクエストを並列で投げる方式で十分。

### 2. フロントエンド: ホーム画面リニューアル（2〜3日）

#### 2-1. カルーセルコンポーネント作成

`src/app/components/anime-carousel.tsx`

```typescript
type AnimeCarouselProps = {
  title: string;
  anime: AnimeSchema[];
  viewAllLink?: string; // 「すべて→」の遷移先
};
```

- 横スクロール + スクロールスナップ
- 左右矢印ボタン（デスクトップ hover 時のみ表示）
- ドラッグスクロール対応（モバイル）
- スクロール位置に応じて矢印の表示/非表示を切り替え

#### 2-2. ホームページ新設

現在のトップページ（`/`）をホーム画面に変更する。
既存の一覧ページは `/browse` に移動する。

```
src/app/routes/
├── index.tsx              # ホーム画面（カルーセル行）★新規
├── browse/
│   └── index.tsx          # 既存の一覧（フィルタ + グリッド）★移動
```

または、トップページ内で「ホームビュー」と「一覧ビュー」をタブ切り替えにする案もある。
ルート分離がシンプルなのでルート分離を推奨。

#### 2-3. データフェッチ

ページの `loader` で複数セクションのデータを並列取得する。

```typescript
loader: () =>
  Promise.all([
    api.getAnimeList({ queries: { recentlyUpdated: true, limit: 20 } }),
    api.getAnimeList({ queries: { year: currentYear, quarter: currentQuarter, limit: 20, sort: "year", order: "desc" } }),
    api.getAnimeList({ queries: { scheduled: true, limit: 20 } }),
  ]);
```

#### 2-4. ナビゲーション更新

ヘッダーのナビリンクを更新する。

```
ホーム (/) → 一覧 (/browse) → 録画 (/recordings)
```

## 設計判断メモ

### トップページの扱い

| 案 | メリット | デメリット |
|----|---------|-----------|
| `/` をホーム化、一覧を `/browse` に移動 | Hulu/Netflix と同じ体験 | ルート変更の影響あり |
| `/` 内でタブ切り替え | ルート変更なし | UIが複雑になる |
| `/` の上部にカルーセル、下部に既存グリッド | 変更最小限 | ページが長くなる |

**推奨: 案1（ルート分離）** — ホーム画面と一覧画面は目的が違うので分離が自然。

### カルーセル実装

| 案 | メリット | デメリット |
|----|---------|-----------|
| CSS `overflow-x` + `scroll-snap` | 依存なし、軽量 | 矢印ボタンのロジックは自前 |
| `embla-carousel-react` | 高機能、ドラッグ操作が滑らか | 依存追加 |

**推奨: CSS scroll-snap** — この用途には十分で、依存を増やさずに済む。矢印ボタンは `scrollBy()` で実装。
