# UI 大規模リファクタリング計画書

ストリーミングアニメ検索 + 録画予約というアプリの本質を踏まえ、現在の UI が縦長になりがち・導線が散らばっている問題を解消するための移行計画。

## 1. アプリのコアユースケース

このアプリで本当にユーザーがやりたいのは次の3つだけ。

| ユースケース | 想定頻度 | 現在の入口 | 必要なクリック数 |
|---|---|---|---|
| **A. 今期/今出ているアニメから「録画予約」する** | 高(週次) | `/` → カルーセル → 詳細 → ボタン | 3 クリック以上 + 縦スクロール |
| **B. 特定タイトルを探して予約 / 詳細確認する** | 中 | `/browse` → 検索 → カード → 詳細 | 2-3 クリック + フィルタ操作 |
| **C. 予約中タイトルの管理(解除 / 録画状態確認)** | 中 | `/recordings` | 1 クリック |

5プロバイダ(Amazon / Hulu / Crunchyroll / ABEMA / Netflix)から横断的に取得しているのが本アプリの最大の価値。**「同じ作品が複数プロバイダにある」「予約一発」「録画状態が一目」が常に手元に出ている UI**にすべき。

## 2. 現状の問題点(機能 / UX / 視覚)

### 2.1 縦スクロールが大きい

| 画面 | 問題 |
|---|---|
| `/` (HomePage) | カルーセル6本 + 配信元グルーピング → 縦に深く積み上がる。`space-y-10` で間隔も広い |
| `/browse` | タイトル/件数 → 検索 → フィルタ行 → アクティブチップ → カードグリッド → ページネーション、と縦に重なる |
| `/anime/:id` | ヒーロー(画像 + メタ + 4ボタン + 説明 + 統計) → エピソードグリッド、と縦に長くなる。エピソードはシーズン別に `space-y-4` で更に伸びる |

### 2.2 横幅を活かせていない (本タスクで一部対応済)

- `__root.tsx` の `max-w-screen-xl` で 1280px 上限 → 大画面で左右が大きく空く
- 既に `__root.tsx` を全幅化済み(現在のブランチ `feat/ui-redesign`)。**だが各ページは縦積み構造のままなので、横が広がっただけでは縦スクロールは減らない**

### 2.3 導線の分散

- ホームのカルーセルから `viewAllLink` で /browse に飛ぶと、フィルタが選択されたフィルタチップに変わり、状況把握に1テンポ必要
- 録画予約状態の確認には3画面の往復が必要(`/` で見つける → `/anime/:id` で予約 → `/recordings` で一覧確認)
- ヘッダーに「録画」へのリンクはあるが、現在の予約数バッジ等の通知がない
- `/anime/:id` の操作ボタンが「自動予約 / 今すぐ録画 / 外部リンク / 更新」と4つ並ぶがグルーピングがない

### 2.4 プロバイダ横断性が活かされていない

[`docs/features/provider-comparison.md`](./provider-comparison.md) でまとめた通り、同一作品が複数プロバイダにある(例: 死亡遊戯 → Amazon + Hulu + Crunchyroll)。`aniListId` で同シリーズはまとまっているが、**詳細画面で「他のプロバイダでも配信中」が見えない**。録画予約は1プロバイダに紐付くので、ここで選び直したい場面がある。

### 2.5 検索 / フィルタの摩擦

- `/browse` で `q`(検索文字列)があるのに、ホームから検索バーへの導線が無い → 一旦 /browse に飛んでから検索する必要がある
- フィルタが Popover 6個 + アクティブチップ + ソート + リセット、と横方向に詰まる。モバイルだとさらに折り返して縦が伸びる

### 2.6 視覚密度の低さ

- `space-y-10`, `gap-4`, `py-8` 等で要素間が広く、1スクリーンに収まる情報量が少ない
- カードグリッドが `xl:grid-cols-5`(= 1280px 時点で 5 列)止まり。フル幅化に対応していない

---

## 3. 移行後のゴール

ユーザーが**スクロールせず**に次の判断ができる UI を目指す。

1. 「今日見られるエピソード」「来週から始まる新作」「予約済みの最新状態」が**ホーム1スクリーン**で把握できる
2. 検索バーは**常に固定**(ヘッダー併設)、画面遷移なしに絞り込みできる
3. 録画予約と録画実行が**カードからワンクリック**で完了する(詳細に飛ばなくてもよい)
4. **詳細は modal / drawer or 3カラム分割**で開き、`/anime/:id` でフルページに切り替えるかは選べる

## 4. 新レイアウト方針

### 4.1 グローバルシェル

```
┌──────────────────────────────────────────────────────────┐
│ Logo  Nav(ホーム/ブラウズ/録画)  [🔍 検索バー]  予約N件  ⚙ │  ← sticky, 全幅
├──────────────────────────────────────────────────────────┤
│                                                          │
│  メインコンテンツ (全幅 px-8 lg:px-12)                    │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

- ヘッダーに**検索バーを常設**(押すと grow / Cmd+K で focus)。`/browse` の SearchBar を吸い上げる
- 「録画」リンクに**バッジ**(scheduled 件数)を出す
- フッターは縮小して `version` だけにする(他は ⚙ 設定 popover に逃がす)

### 4.2 ホーム `/`

**現状**: 6 つのカルーセルを縦に並べる → 縦長

**新**: 上 1/3 を「今やるべきこと」、下を「探索」に分割。

```
┌─ ホーム ─────────────────────────────────────────────────┐
│ [今日の新着エピソード]   |   [予約済みの最新更新]          │  ← 2カラム, 各高さ ~40vh
│  横スクロールカルーセル  |   縦リスト(直近5件)            │
├──────────────────────────────────────────────────────────┤
│ Tab: [今期] [もうすぐ配信] [配信終了予定] [配信元別 ▼]    │
│ ┌────┬────┬────┬────┬────┬────┬────┬────┐                │
│ │ Card│ Card│ Card│ Card│ Card│ Card│ Card│ Card│ … 横並び │  ← 8-10列
│ └────┴────┴────┴────┴────┴────┴────┴────┘                │
└──────────────────────────────────────────────────────────┘
```

- 上 2 カラムは大画面なら横並び、`md` 以下では縦
- 下半分は Tab で `badged` のセクション(NEW_EPISODE / COMING_SOON / EXPIRING / 今期 / 配信元別)を**切り替え**にする。今は全部縦に並べている → タブで圧縮
- 配信元別は今と同じく Tab 内サブセクションでカルーセル展開

### 4.3 ブラウズ `/browse`

**現状**: 縦並びの検索 → フィルタ → グリッド

**新**: 左サイドバー(filter panel) + メインカードグリッド の 2 カラム

```
┌─ ブラウズ ───────────────────────────────────────────────┐
│┌─ Filter ─────┐ ┌─ Grid ───────────────────────────────┐ │
││ 配信元       │ │┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐         │ │
││ □ Amazon    │ ││C │C │C │C │C │C │C │C │C │C │← 10列   │ │
││ □ Hulu      │ │├──┼──┼──┼──┼──┼──┼──┼──┼──┼──┤         │ │
││ □ CR        │ ││C │C │C │C │C │C │C │C │C │C │         │ │
││              │ │└──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘         │ │
││ 年 / 季      │ │ <ページネーション>                     │ │
││ ステータス   │ │                                      │ │
││ バッジ       │ │                                      │ │
││ ソート       │ │                                      │ │
│└──────────────┘ └──────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

- フィルタは Popover 6 個 → サイドバー1個に統合。配信元はチェックボックスで複数選択可
- カードクリックで右ペインに**ドロワー詳細**を開く(ページ遷移はしない)。「フルページで開く」リンクで `/anime/:id` に行ける
- モバイルでは Popover 群を 1 つの「フィルタ」ボタン → bottom-sheet に集約

### 4.4 詳細 `/anime/:id`

**現状**: 縦長ヒーロー + 縦長エピソードグリッド

**新**: 2 カラム(ヒーロー左 / エピソード右)

```
┌─ 詳細 ───────────────────────────────────────────────────┐
│┌─ Hero ───────┐ ┌─ Episodes ──────────────────────────┐ │
││ Cover Image │ │ [Season 1] [Season 2] [Movie]       │ │  ← seasonタブ
││              │ │┌──┬──┬──┬──┬──┐                     │ │
││ Title        │ ││E │E │E │E │E │ ← 4-5列              │ │
││ Badges       │ │├──┼──┼──┼──┼──┤                     │ │
││ [予約][録画]  │ ││E │E │E │E │E │                     │ │
││ [更新][外部] │ │└──┴──┴──┴──┴──┘                     │ │
││              │ │                                      │ │
││ 配信元: ▼    │ │                                      │ │
││  ・Amazon    │ │                                      │ │
││  ・Hulu      │ │                                      │ │
││  ・CR        │ │ ← aniListId で集約された他provider版 │ │
││              │ │   各行で「このプロバイダで予約」ボタン│ │
│└──────────────┘ └──────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

- 左: 既存のヒーロー要素を縦に置く。ボタンは2行に圧縮(`[予約][録画]` / `[更新][外部]`)
- 左下に**「同一作品の他プロバイダ」リスト**を追加(`provider-comparison.md` 由来の差異 — entityType, episode count, releaseDate 差 — をミニ表示)
- 右: シーズンを Tab 化、エピソードは現在の `grid-cols-4` 維持、フル幅化で `xl:grid-cols-5` まで
- スクロールするのは右カラムだけ(`sticky` ヒーロー)

### 4.5 予約一覧 `/recordings`

現在は縦リスト1本(`divide-y`)。**現状でほぼ問題なし**だが、

- ヘッダー検索バー + フィルタ(録画済み / 未録画 / 配信終了予定)を追加
- 一括解除 / プロバイダごとのグループ表示(任意)

## 5. プロバイダ機能の現状問題と UI から見える改善余地

`provider-comparison.md` / `provider-fetch-counts.md` / `lambda-processing-flow.md` を踏まえた、**UI に出すべき/今は隠れている課題**:

| 項目 | 現状 | UI 上の問題 | 対応 |
|---|---|---|---|
| プロバイダ間タイトル表記揺れ(`A Silent Voice` vs `映画 聲の形`) | バックエンドで AniList ID で集約 | `/anime/:id` では1プロバイダ版しか出ない | 詳細画面で「他プロバイダ版」リスト |
| Hulu の episodeNumber 欠番(原作回ベース) | merger で吸収 | エピソード番号がプロバイダ間で違う旨が見えない | エピソードカードに `provider/番号` を small で出す |
| `entityType` 不一致(Amazon = movie, Hulu = tv) | DB は両方保持 | 同シリーズ集約ビューで mix されて見える | type バッジで明示 / フィルタに `映画/TV` 追加 |
| 配信終了予定(EXPIRING) | badged API で出すが、ホームで1カルーセル分しか見えない | 重要度高なので、もっと上に置きたい | ホーム上段の「今日やるべきこと」に組み込み |
| 録画ボタン押下後の状態フィードバック | toast のみ | ボタン側に loading / 成功表示が薄い | スピナー + 成功状態の視覚 |
| 録画予約ON時のエピソードカウント変動 | 現状なし(ホームは静的) | 予約済みなのに「未予約として」見える可能性 | カードに録画済みインジ追加(Filter で隠せる) |

## 7. フェーズ分割 (= PR 単位)

`/feedback_pr_per_phase` の通り **1 PR = 1 関心**。1 PR ごとに `develop` にマージ可能、デザインがおかしければロールバックも可能にする。

### Phase 0: 全幅化(済 / 本ブランチ)
- `__root.tsx` の `max-w-screen-xl` 削除、padding 維持
- 既存ページはそのまま広がる(visual regression 限定的)

### Phase 1: グローバルシェル刷新
- ヘッダー sticky 検索バー追加(`Cmd+K`)
- 録画リンクにバッジ追加
- フッター縮小
- 横 padding を `px-6 lg:px-8 xl:px-12` に
- 影響: `__root.tsx`、新規 `app/components/global-search-bar.tsx`
- 受け入れ基準: 既存 URL すべて従来通り表示。検索バーから query を入れると `/browse?q=...` に飛ぶ

### Phase 2: ホーム 2/3 段構成
- 上段: 「新着エピソード」+「予約済み更新」を 2 カラムで
- 下段: 6 セクションをタブにまとめる
- 影響: `app/routes/index.tsx`、必要に応じて `AnimeCarousel` props 拡張
- 受け入れ基準: 1280px で 1.5 スクロール以内に全コンテンツ。`xl` で 1 スクロール

### Phase 3: ブラウズの左サイドバー化
- フィルタを `<aside>` に統合、Popover 群を撤去
- カードグリッド `xl:grid-cols-6 2xl:grid-cols-8`
- 影響: `app/routes/browse/index.tsx`、新規 `browse/-components/filter-sidebar.tsx`
- 受け入れ基準: フィルタ操作 0 スクロールで完結
- メモ: 当初計画にあった「カードクリックで Drawer 詳細」は Phase 4 に統合(詳細 2 カラム化と一緒にやる方が素直)

### Phase 4: 詳細 2 カラム化 + プロバイダ横断ビュー + ブラウズ→ドロワー
- 左ヒーロー sticky / 右 シーズンタブ + エピソードグリッド
- 左下に「同一作品の他プロバイダ」(aniListId クエリ)
- ブラウズ画面: カードクリックで Drawer 詳細(closeable / "フルページ" リンク付き)
- 影響: `app/routes/anime/$id/index.tsx`, `anime-hero.tsx`, `episode-grid.tsx`、新規 `related-providers.tsx`、`app/components/anime-drawer.tsx` + API 追加(`GET /api/anime?aniListId=...`)
- 受け入れ基準: 詳細画面で縦スクロールがエピソード一覧分のみ。他プロバイダ版から予約ボタンが効く。Drawer 詳細から予約ボタンが効く

### Phase 5: 予約一覧の機能拡張
- ヘッダー検索バー + フィルタ(録画済 / 未録 / EXPIRING)
- 一括解除
- 影響: `app/routes/recordings/index.tsx`
- 受け入れ基準: 50 件以上の予約でも 1 スクロール内に検索 + フィルタ + 上位 10 件が見える

### Phase 6: デザイントークン整理 (任意)
- `space-y-10` → `space-y-6`、`gap-4` → `gap-3` の一括見直し
- shadcn primitive は **触らない**(`feedback_no_default_tweak_in_ui_primitives`)、上書きは利用側 className で
- card thumbnail `aspect-[2/3]` の徹底

## 8. 制約 / 守るルール (記憶ベース)

- **shadcn UI primitives は変更しない** — Button / Dialog / Popover などはそのまま、利用側で `className` 上書き
- **`??` 演算子禁止** — フロント全般。`||` フォールバックも空文字 sentinel も禁止、ternary or 非null 引数で押し付け
- **データ取得は `useSuspenseQuery(ies)` + QueryBoundary**。`useEffect` で fetch しない
- **フロント永続化は `atomWithStorage`**(zod safeParse 込み)。`browseFiltersAtom` の既存パターンを踏襲
- **コンポーネントファイル名は `kebab-case`**(`anime-drawer.tsx`)、`export` 識別子は Pascal
- **ルートparam は zod で検証**(既に `browse` は `validateSearch` で対応済、踏襲)
- **PR は Phase ごと**

## 10. 想定外の質問への回答

- **Q. なぜ Drawer なのか? Modal や route 遷移ではダメ?**
  A. 遷移すると下に並ぶ予約候補のコンテキストが消える。Modal は背景操作不可で「複数候補比較」しにくい。右側 Drawer は左に grid が残り、選び直しがスムーズ。
- **Q. プロバイダ横断ビューを詳細画面に出すと、aniListId が無いタイトル(`UNIDENTIFIED`)はどうする?**
  A. その場合は出さない(空欄)。`UNIDENTIFIED` で `aniListId == null` のレコードは admin で紐付ける既存運用に従う(`/admin/unidentified` ページ)。
- **Q. ホーム上段の「今日やるべきこと」は何を出す?**
  A. (a) 新着エピソードのうち過去 24h 配信、(b) `scheduled = true` で前回録画より新エピが追加されたもの、の 2 軸。両方 0 件のときは「もうすぐ配信」のカルーセルを差し込む。
